# simulationDTN
changes in the-one simulator for our master's thesis
including:


1- reports created for result interpretation


2- updated files from the DTN the ONE simulator


3- working settings file


4- updated routing algorithm


5- python scripts for result interpretation


6- images created from the scripts


7- csv files from aggregation of data created from the runs

for the reports sim:

    battery result: ran 100 simulations with different seed each time

    network load: ran every load level with every routing algoritem 50 times total each run with different seed: 450 simulation

    buffer overhead: ran 10 runs with different buffer sizes and seeds for both routing algorithems: total 20

    density vs delivery rate study: ran 20 simulation runs per density for 9 different densities total: 180 simulation

    for each densities and network load studies the settings files are included 
    
    for the battery results the uploaded file updated settings in the one.txt is the one used 
    
    for the buffer overhead the updated settings in the one.txt is used with all groups set to one buffer size
